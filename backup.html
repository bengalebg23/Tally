Site backup

Saves the data every one of your apps keeps on this phone (Meal Rota, Money Flow, Home, Tally…) into one file, so you can reset Chrome for this site and put it all back.

On this phone now
Step 1 — before resetting

The file goes to your Downloads. Check it's there before step 2.

Step 2 — reset Chrome for this site
  1. Chrome ⋮ → Settings → Site settings → All sites
  2. Tap bengalebg23.github.io → Delete data (or Clear & reset)
  3. Come back to this page (same address)
Step 3 — after resetting

Pick the file you saved in step 1. Then open Tally and install it.

Afterwards

Delete the backup file from Downloads once everything's back. It holds Meal Rota and your other apps' data in plain form, and Tally's data protected only by your PIN.
